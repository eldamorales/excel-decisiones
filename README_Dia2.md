# Excel para la toma de decisiones. Día 2

Material didáctico de la Dra. Elda C. Morales.

Abre dia2.html en tu navegador. Es autónomo: incluye el Excel, la presentación y diez CSV descargables. Requiere JavaScript y no usa servicios externos para sus ejercicios. El avance permanece en el navegador y puede descargarse como JSON.

## Uso paso a paso
1. Descarga el libro desde el tutorial y guarda una copia.
2. Recorre Texto, Busquedas, Pedidos y Filtro siguiendo el HTML.
3. Intenta cada Rn_Datos antes de consultar Rn_Solucion.
4. Importa CSV como UTF-8, delimitador coma, códigos como Texto.
5. Comprueba los controles de cada reto y conserva las fórmulas.

Microsoft 365, Excel 2021 o 2024 para BUSCARX/FILTRAR. En 2016/2019 usa BUSCARV y el filtro de tabla para la práctica compatible. Los menús pueden variar entre Windows y Mac.

Los datasets son sintéticos y sus importes están en MXN. Umbral de margen didáctico: 15%. Hay dos #N/D intencionales en Busquedas!B13:C13. R3 conserva seis claves sin catálogo y R5 contiene seis ventas cero válidas.

## Publicación
Sube dia2.html a la raíz del mismo repositorio del Día 1. La dirección será /excel-decisiones/dia2.html. El index.html del Día 1 se conserva. El HTML incorpora sus descargas, por lo que no requiere subir archivos Office por separado.

## Validación docente
Revisa originales, claves, fórmulas, filtro con distintos criterios, controles numéricos y reglas de formato. El tutorial ofrece comprobación formativa y una rúbrica; no califica automáticamente los archivos entregados.
