# Excel para la toma de decisiones. Día 1

**Autora: Dra. Elda C. Morales**

Tutorial interactivo de rangos, nombres, tablas, errores, HOY y AHORA. Incluye cinco retos de 24, 36 + 4, 48, 60 y 120 registros y una guía para la actividad final de 3,500 registros.

## Abrir el tutorial

1. Descomprime el paquete completo.
2. Abre `index.html` con un navegador reciente.
3. Los archivos de práctica están integrados en el HTML. La carpeta `recursos` ofrece además copias individuales.
4. Empieza en **Antes de comenzar** y usa los enlaces del recorrido.
5. Abre los XLSX en Excel de escritorio para repetir los pasos y revisar las fórmulas.

No requiere instalación, servidor, claves, cuentas ni bibliotecas externas. El HTML contiene sus estilos, lógica, datasets y archivos de práctica descargables. Funciona también al compartir únicamente `index.html`. Las fuentes oficiales se abren únicamente cuando eliges sus enlaces.

## Archivos

- `index.html`: tutorial interactivo.
- `recursos/Dia1_Presentacion.pptx`: presentación del día 1.
- `recursos/Dia1_Ejercicios_Resueltos.xlsx`: ejemplos resueltos del día 1.
- `recursos/Cinco_Retos_Dia1.xlsx`: datos iniciales y soluciones con fórmulas. Incluye comprobantes ficticios y filas nuevas.
- `recursos/reto_*_datos.csv`: datos para cada reto.
- `recursos/reto_*_solucion.csv`: valores resueltos, sin fórmulas.
- `recursos/reto_2_nuevas_filas.csv`: cuatro registros para ampliar el segundo reto.

Los datos de los cinco retos son ficticios. Los importes de esos casos están en MXN. El archivo original de la actividad final, `ecommerce_sales_data.xlsx`, lo distribuye la docente y no se incluye en este sitio. Su perfil se revisó para preparar la guía. El tutorial conserva sus siete encabezados reales y aclara la diferencia entre una columna completa y el valor de una fila.

## Fórmulas y fechas

Las instrucciones usan fórmulas en español. Adapta el separador de argumentos `;` o `,` a tu configuración regional. El XLSX guarda fórmulas en el formato interno estándar y Excel las muestra en su idioma.

Las soluciones de los retos utilizan un corte fijo de **26/10/2026** para poder comparar resultados. HOY y AHORA se actualizan al recalcular. El simulador web calcula únicamente los casos definidos y no sustituye el motor de Excel.

## Avance y privacidad

Las marcas, respuestas y reflexiones se guardan en el almacenamiento local de este navegador. No se transmiten al sitio ni a un servicio de calificaciones. **Guardar avance** descarga una evidencia JSON; no sincroniza el avance con otros dispositivos. El navegador puede impedir o borrar el almacenamiento local.

## Publicación en GitHub Pages

1. Crea un repositorio nuevo para este material. Para GitHub Free, elige público si utilizarás Pages sin un plan adicional.
2. Sube `index.html`, `.nojekyll` y `README.md`. La carpeta `recursos` es opcional: las descargas ya están integradas en el HTML.
3. En el repositorio abre **Settings > Pages**.
4. En **Build and deployment > Source**, elige **Deploy from a branch**.
5. Selecciona la rama que contiene los archivos, normalmente `main`, y la carpeta `/(root)`.
6. Guarda. Cuando GitHub termine el despliegue, usa el enlace mostrado en Pages. No deduzcas que ya está publicado solo porque los archivos aparecen en el repositorio.
7. Abre el enlace, navega por un reto y prueba la descarga de los XLSX.

Si no encuentras Pages, revisa permisos, plan y visibilidad. Un repositorio nuevo evita sobrescribir otro sitio. El tutorial no necesita un proceso de compilación ni GitHub Actions propio.

Fuente oficial de publicación: https://docs.github.com/es/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site (consulta: 26 de octubre de 2026).

## Validación para uso docente

- Los archivos de datos y solución corresponden al mismo caso y están identificados.
- Los importes de control se obtienen de los datasets completos.
- Las ventas cero del reto 5 se conservan. Su margen se presenta como **Sin ventas**.
- Las pérdidas del reto 5 permanecen negativas y la señal visual no depende solo del color.
- Los errores intencionales del libro base permanecen señalados junto a su corrección.
- El avance personal no constituye una calificación automática.
