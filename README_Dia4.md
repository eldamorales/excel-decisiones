# Día 4. Bases de datos y tablas dinámicas
Dra. Elda C. Morales.

## Uso
1. Abre dia4.html en un navegador con JavaScript o visita el tutorial publicado.
2. Descarga el libro y guarda una copia con tu nombre.
3. Sigue el caso base antes de intentar los cinco retos.
4. Usa Excel de escritorio para Filtro avanzado, el comando Subtotales y el recorrido completo.
5. Comprueba las fórmulas, los criterios y los totales antes de compartir.

Los datasets son sintéticos, con pedidos ficticios de enero a septiembre de 2026 e importes MXN. Cada fila representa un pedido. CSV UTF-8 con coma: importa Pedido como texto y Fecha como fecha ISO.

El libro contiene tablas y gráficos dinámicos nativos con cachés guardadas, fuentes en tablas nativas, reglas de validación y fórmulas de control. Corrección del 29 de octubre de 2026: se reparó la estructura OOXML del libro. Sus 58 partes de hojas de cálculo, gráficas y dibujos pasan la validación de esquema; una copia se abrió y recalculó en LibreOffice, conservando las 19 hojas, 6 tablas dinámicas y 6 gráficas. No se comprobó la apertura en Microsoft Excel en esta revisión. Comprueba Actualizar y los filtros en tu versión de Excel. Las fórmulas se recalculan, las tablas dinámicas requieren actualizar y las extracciones resueltas requieren repetir el filtro si cambia la fuente.

XLSX no contiene macros VBA. El tema de macros es conceptual y la demostración web es una simulación. No requiere habilitar macros. El avance se almacena en el navegador y se puede descargar como JSON.

Las soluciones incluyen CSV ordenados, extracciones y resúmenes de tablas dinámicas. Las fórmulas visibles del tutorial usan nombres en español y punto y coma. Adapta el separador a tu configuración. El archivo XLSX almacena las fórmulas con la sintaxis interna de Excel.
